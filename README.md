# CET6 Trainer · 六级真题每日打卡

零依赖纯前端应用：全部 76 套六级真题（2015-06 至 2026-06，3315 题），每日轮换打卡、自动判题、考点解析、自适应遗忘曲线错题复习、统计连击、备份导出。支持 PWA：手机浏览器「添加到主屏幕」即可像 App 一样离线使用。

## 使用

直接打开 GitHub Pages 地址即可，无需安装。

- 打卡记录保存在浏览器 localStorage，换设备用「备份」页导出/导入 JSON
- 错题本按遗忘曲线智能调度：稳固度动态调整复习间隔，逾期题优先重练
- 以后扩题：bank JS 放入 `bank/`，`index.html` 末尾加一行 `<script src="bank/..."></script>`

## 结构

- `index.html` — 界面与交互；`core.js` — 判题/遗忘曲线/清单调度（零依赖纯函数）
- `bank/` — 76 套结构化题库；`manifest.json` + `sw.js` + 图标 — PWA
