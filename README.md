# CET6 每日打卡 · 使用说明

零成本、零安装的英语六级真题练习工具。双击打开即用，手机电脑都能跑。

## 快速开始（10 秒）

1. 把本文件夹放在任意位置（例如 `D:\CET6`）
2. 双击打开 `app\index.html`（用 Chrome / Edge 浏览器）
3. 按「今日清单」从上往下做，做完自动打卡

就是这么简单——不需要安装任何东西，不需要联网（只有听力音频是在线播放的）。

## 每天怎么用

- **今日清单（预算制）**：每天自动生成 25–40 分钟的任务，优先级为「到期错题复习（≤10 分钟）→ 写作/翻译（每周六一篇，隔周轮换）→ 新题」。新题按真题天然完整单元出：听力同卷连续 4 题（共用一段录音）、选词填空整篇、信息匹配整篇、仔细阅读整篇 5 题；组内题号连续，最近考期优先（2026 → 2015 逐卷推进）。完成全部清单组自动打卡。
- **没时间的日子**：点「底线模式」，记几分钟也保住连击——这是防弃坑的关键设计。
- **想多练**：点加练按钮，不设上限，时间照常计入。
- **做题界面**：整组同屏——文章/音频入口在上、题目在下逐题排列，上下题语境连贯；逐题点选即时存草稿，中途退出回来可续做，组底一次提交统一判分。
- **错题本**：做错的题自动进错题本，按自适应遗忘曲线（间隔 1–60 天动态伸缩）安排重练，答对 5 次自动出库；每天的到期错题会自动进当日清单的复习组。也可以随时手动调出来重练。
- **每题答完**：立即判题 + 显示考点标签 + 完整解析（定位、信号、同义替换、排除项）。

## 目录说明

```
CET6\
├── app\                ← 软件（双击 index.html 即用）
│   ├── index.html      ← 主程序，双击这个
│   ├── core.js         ← 核心逻辑（打卡/清单/遗忘曲线/统计）
│   └── bank\           ← 题库（以后加新卷放这里）
├── bank\
│   ├── raw\            ← 真题原始文件（Word 卷面 + 解析 PDF）
│   └── json\           ← 转录好的结构化题库 + 自检报告
├── backup\             ← 打卡记录备份（每周导出一次存这里）
└── docs\               ← 验收记录（测试输出 + 界面截图）
```

## 打卡数据保存在哪？怎么换设备？

打卡记录保存在**浏览器的本地存储**里（不上传任何服务器）：

- **每周备份一次**：软件内「备份」页 → 导出备份 JSON → 存到 `backup\` 文件夹
- **换电脑/手机**：旧设备导出 → 新设备打开 index.html → 备份页导入，无缝衔接
- ⚠️ 清理浏览器数据会丢打卡记录，先导出再清理
- ⚠️ 尽量固定用同一个浏览器打开

## 手机上用

把整个 `CET6` 文件夹发到手机（微信文件传输助手 / 网盘均可），用手机浏览器打开 `app\index.html` 即可。数据同样在本机浏览器里，换设备记得导出导入。

- **写作/翻译题面按日期在全部 76 套间轮换**，一年内每套都会轮到，不再是固定一套
- **错题本·自适应遗忘曲线（P5）**：每道错题带「稳固度」系数（答对 +0.1 / 答错 -0.2，区间 1.3~2.8），复习间隔 = 上次间隔 × 稳固度（1→2→5→13→…天，上限 60），连续答对 5 次自动出库；错题本页按「逾期越久 > 错次越多 > 稳固度越低」智能排序，「智能复习」一键练最薄弱的 20 题；旧打卡记录自动迁移，无需任何操作
- **PWA 适配（P5）**：线上版（GitHub Pages）可在手机浏览器「添加到主屏幕」，像 App 一样全屏打开；题库缓存后二次打开秒开、离线可刷（打卡记录照常本地保存）。本地 file:// 打开不受影响
- 以后加卷：告诉 AI「把 XXXX 年 X 月真题加入题库」，新生成的 `cet6-xxxx-x-x.js` 放进 `app\bank\`，并在 `index.html` 底部 `</body>` 前加一行：

```html
<script src="bank/cet6-xxxx-x-x.js"></script>
```

## 常见问题

**双击打开后样式乱 / 白屏？** 换 Chrome 或 Edge 浏览器打开（右键 index.html → 打开方式）。

**听力怎么听？** 做听力组时页面顶部有「打开在线听力页」链接，点开新标签页播放音频，听完后回到做题页作答。这一步需要联网。

**清了浏览器数据还有救吗？** 有——只要 `backup\` 里有最近的备份 JSON，导入即可恢复到备份那天。
